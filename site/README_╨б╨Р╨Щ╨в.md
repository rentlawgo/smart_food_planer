# Сайт «Умный планировщик продуктов»: запуск, бесплатная публикация и управление

Весь путь бесплатный: GitHub (хранение и публикация) + Cloudflare Worker (приём сообщений из формы). Домен не нужен: сайт получит бесплатный адрес вида `ваш-логин.github.io`. Командная строка не нужна, всё делается в браузере.

Проверить, как выглядит сайт, можно до публикации: откройте `index.html` двойным щелчком.

---

## ЧАСТЬ 1. Прямая отправка сообщений из формы в ваш Telegram

Токен бота нельзя вставлять в код сайта: его увидит любой посетитель. Поэтому между сайтом и Telegram стоит бесплатный «посредник» (Cloudflare Worker). Токен хранится только у него.

### 1.1. Создайте бота
1. В Telegram откройте **@BotFather** → отправьте `/newbot`.
2. Придумайте название и логин (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `123456:ABC-DEF…`. Никому его не показывайте. Если он утёк — в @BotFather отправьте `/revoke`.

### 1.2. Узнайте свой chat id
1. Откройте своего нового бота и нажмите **«Запустить»**, затем напишите ему «привет». Без этого бот не сможет вам писать.
2. В браузере откройте адрес `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (вместо `<ТОКЕН>` — ваш токен).
3. Найдите в ответе `"chat":{"id":123456789` — это число и есть **chat id**.

### 1.3. Создайте Worker в Cloudflare
1. Зарегистрируйтесь на **dash.cloudflare.com** (бесплатно, без карты).
2. Меню **Workers & Pages** → **Create** → **Create Worker** → имя `feedback` → **Deploy**.
3. Нажмите **Edit code**, удалите всё, вставьте содержимое файла `worker/feedback-worker.js` → **Deploy**.
4. Откройте **Settings → Variables and Secrets** и добавьте:
   - `BOT_TOKEN` — токен бота, тип **Secret**;
   - `CHAT_ID` — ваш chat id;
   - `ALLOWED_ORIGINS` — адрес сайта, например `https://ваш-логин.github.io` (без пути и без `/` в конце). Несколько адресов — через запятую.
5. **Deploy** ещё раз.
6. *(Рекомендуется, 2 минуты)* Строже защита от спама: **Storage & Databases → KV → Create** (имя `rate`), затем у Worker: **Settings → Bindings → Add → KV namespace**, имя переменной строго `RATE`.
7. Скопируйте адрес Worker (`https://feedback.ваш-аккаунт.workers.dev`) и вставьте в `config.js` → `feedback.endpoint`.

Названия пунктов в панели Cloudflare иногда меняются, но смысл тот же.

**Проверка:** откройте сайт, отправьте сообщение через форму — оно должно прийти в чат с ботом.

**Защита от спама** встроена: принимаются только запросы с вашего сайта, скрытое поле для роботов, проверка «слишком быстро», лимит 5 сообщений в час с одного адреса. Бесплатный лимит Cloudflare Workers — 100 000 запросов в сутки.

## ЧАСТЬ 2. Бесплатная публикация

### Вариант А (рекомендую): GitHub Pages
1. Зарегистрируйтесь на **github.com** (бесплатно).
2. **+ → New repository** → имя, например, `smart-food-planner-site` → **Public** → **Create repository**.
   *Совет:* если назвать репозиторий точно `ваш-логин.github.io`, сайт будет доступен по короткому адресу `https://ваш-логин.github.io/`.
3. На странице репозитория нажмите **uploading an existing file** и перетащите **всё содержимое папки сайта** (index.html, config.js, assets, worker, tools и остальное) → **Commit changes**.
4. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main, папка / (root) → Save.**
5. Через 1–2 минуты вверху страницы появится адрес сайта. Он бесплатный, постоянный и с HTTPS.
6. Впишите этот адрес (без пути) в `ALLOWED_ORIGINS` в Worker (часть 1.3, шаг 4).

### Вариант Б: Cloudflare Pages
Cloudflare → Workers & Pages → Create → Pages → Connect to Git (выберите тот же репозиторий) → сборка не нужна, папка вывода `/`. Адрес будет `название.pages.dev`. Минус: файлы больше 25 МиБ не принимает, поэтому установщик всё равно нужно хранить в GitHub Releases.

### Свой домен (необязательно, платно)
Адрес `github.io` полностью рабочий. Свой домен (`смартфуд.рф`, ~1–2 тыс. руб./год) нужен только для красоты. Привязывается в **Settings → Pages → Custom domain**. Новый адрес добавьте в `ALLOWED_ORIGINS`.

## ЧАСТЬ 3. Как управлять сайтом дальше

Любое изменение: откройте нужный файл в репозитории на GitHub → значок карандаша ✏️ → правьте → **Commit changes**. Сайт обновится сам через 1–2 минуты (если не видно — обновите страницу через `Ctrl+F5`).

| Что нужно | Что делать |
|---|---|
| Поменять контакты | `config.js` → `developer` |
| Добавить новость | `config.js` → массив `news`, добавьте строку `{ date: '2026-12-01', tag: 'Обновление', title: '…', text: '…' }` |
| Изменить тексты на сайте | `index.html` |
| Изменить цвета и оформление | `assets/styles.css` (цвета — в начале файла) |
| Откатить ошибку | файл → **History** → нужная версия → **Revert** |

### Как выложить приложение для скачивания
1. В проекте приложения выполните `npm run dist` → установщик появится в папке `dist`.
2. **Переименуйте файл латиницей без пробелов:** `SmartFoodPlanner-Setup-1.0.0.exe`.
3. Посчитайте контрольную сумму (командная строка Windows): `certutil -hashfile "C:\путь\SmartFoodPlanner-Setup-1.0.0.exe" SHA256` — нужна вторая строка (64 символа).
4. В репозитории откройте **Releases → Draft a new release** → тег `v1.0.0` → перетащите файл установщика → **Publish release**. Файл может весить до 2 ГБ.
5. Правый клик по файлу в релизе → **Копировать адрес ссылки**.
6. Откройте `config.js` и заполните: `download.url` (ссылка), `version`, `size`, `date`, `sha256`. Сохраните (Commit). Кнопка «Скачать» заработает.
7. **Для новой версии** повторите шаги 1–6 с новым тегом (`v1.0.1`) и добавьте новость.

### Документы
Ссылки `https://ваш-адрес/#terms` и `https://ваш-адрес/#privacy` сразу открывают нужный документ — их можно использовать в приложении. Если вы меняли тексты в приложении (`renderer/js/legal.js`), обновите их и на сайте командой: `node tools/update-legal.js "C:\путь\к\legal.js"`. Тексты — шаблон без юриста: перед публичным запуском покажите их юристу.

## Что бесплатно и где границы
- GitHub (репозиторий, Pages, Releases) и Cloudflare Workers — бесплатные тарифы без срока действия. Лимиты: Workers — 100 000 запросов/сутки; Cloudflare Pages — 25 МиБ на файл и 500 сборок/мес. Условия бесплатных тарифов могут измениться.
- Платным может быть только свой домен и цифровая подпись приложения (снимает предупреждение Windows).

## Если сайт не открывается у части пользователей
Некоторые провайдеры и страны ограничивают доступ к отдельным хостингам. Проверьте сайт с разных сетей. Если проблема подтвердится, решение — свой домен или другой хостинг. Сами файлы переносятся без изменений.
